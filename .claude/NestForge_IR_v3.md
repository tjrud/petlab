## 2. 슬라이드별 최종 문구

### 1. TITLE
- 헤드라인: 소형 반려동물 케이지 구조물 맞춤 설계 플랫폼 (로고 아래 한 줄)

- 배경 사진은 Canva 생성 이미지. 실제 출력물 사진으로 교체 권장

### 2. PROBLEM
- 헤드라인: 케이지에 맞는 안전한 구조물을 구하기 어렵습니다
- 1 규격 고정: 케이지 크기·입구 규격은 집마다 다른데 시판 용품은 규격이 고정됨
- 2 흩어진 기준: 종·크기마다 필요한 기준이 다른데 정보는 커뮤니티 후기에 흩어져 있음
- 3 제작 장벽: 3D 모델링 지식이나 외주가 필요함. 대충 맞는 것을 쓰면 끼임·낙상 사고로 이어짐
- 출처: PetMD, 시리안 햄스터에게 작은 쳇바퀴 사례 / 독일 동물보호연맹 '동물복지에 반하는 용품' 입장문(2024.06) [확정]
- [확인 필요] 보호자 설문이 생기면 카드 위에 "응답자 N명 중 N%가 맞는 구조물을 찾지 못함" 한 줄 추가

### 3. SOLUTION
- 헤드라인: 요구사항 입력만으로 케이지에 맞는 구조물을 설계합니다

- 2 요구사항 입력: "출입구가 두 개 있는 은신처를 만들어 주세요"
- 3 AI 맞춤 설계: 종별 사육 기준 반영
- 4 3D 확인·수정 요청: 3D로 미리 보고 글로 수정 요청
- 5 STL·3MF 파일 받기: 프린터가 없으면 당사가 출력해 택배 배송
- 박스: MVP 운영 중 · petlab-sage.vercel.app · 구조물 4종 은신처·터널·램프/계단·모래목욕통 · 햄스터 드워프·골든 [확정]
- 오른쪽: 운영 사이트 첫 화면, 3D 미리보기 실제 캡처

### 4. TECHNOLOGY (NestForge만의 기술 강조)
- 헤드라인: 종별 안전 기준을 내장한 설계·검증 엔진은 NestForge뿐입니다
- 1 듣기(AI): 요구사항을 읽고 구조물 종류와 치수를 정리한 '치수표'만 작성. 형상은 직접 그리지 않음
- 2 만들기(설계 틀): 미리 검증한 설계 틀이 치수표대로 형상 생성. 서포트 없이 출력되는 자세까지 틀이 결정
- 3 검사하기(안전 검사): 출입구 폭 · 끼임 틈 · 벽 두께 · 경사각 · 출력 가능 여부 점검. 기준 미달 항목이 있으면 파일 다운로드 차단
- 박스 제목: NestForge만의 구조
- 박스 본문: 종별 기준 데이터 + 검증된 설계 틀 + 출력 전 안전 검사를 한 엔진에 담았습니다. 범용 AI 설계 도구에는 없는 조합입니다.
- 차별점 3가지 (공간이 되면 박스 옆에 작은 글씨로):
  1. 종별 안전 기준을 데이터(규칙 파일)로 보유. 값마다 출처 주석, 파일 교체만으로 전문가 검수 반영
  2. AI는 해석만, 형상은 검증된 설계 틀이 생성. 같은 입력이면 항상 같은 결과
  3. 출력 전 10개 항목 자동 검사, 미달 시 다운로드 차단. 배포 후 형상 코드가 바뀌면 저장된 설계를 자동 재검증
- 각주: 기준 출처 독일 수의사 동물보호협회(TVT) · 독일 동물보호연맹. 예: 골든 햄스터 출입구 최소 7cm(볼주머니 포함), 드워프 5cm [확정]

## 3. 다른 세션에서 Canva에 적용할 작업 지시

공통

장별
1. 1장: "TITLE" 라벨 추가(다른 장과 같은 서식). 헤드라인 두 상자("소형 반려동물 케이지 구조물" / "맞춤 설계 플랫폼")를 한 문장으로 합치고 46px, 너비 1,020px.
2. 2장: 두 상자를 한 문장으로. 64px, 너비 1,500px, 위치 top 150.
3. 3장: 두 상자를 한 문장으로. 60px, 너비 1,230px(오른쪽 캡처와 겹치지 않게), top 130.
4. 4장: 세 줄 헤드라인을 한 문장으로. 60px, 너비 1,700px. "설계 원칙" 박스 제목과 본문을 위 문구로 교체하고 본문 상자 너비 800px.
5. 5장: 두 상자를 한 문장으로. 60px, 너비 1,760px.

## 5. 질의응답 준비

### 기술 (딥테크 심사 대비)
- 왜 딥테크인가, 해자는 무엇인가 → 종별 기준 데이터(값마다 출처 주석), 파라메트릭 설계 틀 + 결정적 배치기 + 검증 게이트, 배포 간 형상 변경 시 저장 설계 자동 재검증, 쌓이는 설계·수정 이력 데이터
- 경쟁사가 따라 할 수 있지 않나 → 범용 AI 설계 도구는 형상을 AI가 직접 만들어 검증 구조가 없고, 종별 기준 데이터도 없음. 기준 데이터와 검증 체계는 종을 늘릴수록 쌓이는 자산
- LLM이 치수를 잘못 내면 → 허용 범위 밖 값은 스키마에서 거부하고 재시도, 기준 밖 값은 자동 보정 후 표시, 검증 오류가 남으면 다운로드 차단
- 왜 AI가 직접 모델링하지 않나 → AI가 만든 형상은 안전성을 검증하기 어렵고, 동물 안전이 걸려 있어 AI 역할을 해석으로 한정
- 검사 항목 → 케이지 적합, 겹침, 끼임 틈새(구조물·벽·천장), 출입구 막힘, 개구부 크기, 합사 시 출입구 개수, 벽 두께(설계값 + 메시 실측), 오버행, 출력 공간, watertight
- 종·구조물 확장 비용 → 종 추가는 규칙 파일 항목 추가, 구조물 추가는 설계 틀 등록만으로 AI 입력 형식·검사에 자동 반영
- LLM 비용 → 설계 1건 100~300원 [가정]. 1크레딧 1,000원이면 원가율 10~30%. 회원·IP·전체 사용량 상한으로 관리
- 왜 구독이 아니라 충전식인가 → 구조물 설계는 매달 하는 일이 아니라 필요할 때 몇 번 하는 일. 쓴 만큼만 내는 선불 크레딧이 보호자 부담이 적고, 무료 3크레딧으로 진입 장벽을 낮춤. 충전 보너스로 큰 단위 충전을 유도

### 안전·기준
- 3D 출력물을 갉아도 안전한가 → 완전히 안전하다고 증명된 소재는 없음. PLA·PETG는 조건을 지키면 사용 가능하다는 조사 결론이고 국내 인기 브랜드도 PLA로 판매 중. 햄스터 대상 연구는 없어 '증명됐다'고 말하지 않음. 대응: 갉음 고려 최소 벽 두께(드워프 2.4mm·골든 3.0mm), 식품접촉 등급 필라멘트, 소재·사용 수칙 가이드 3편
- 종별 기준은 누가 검증했나 → 전문가 검수 전. 값마다 출처와 '임시' 표시, 검수 결과는 파일 교체로 즉시 반영. 2027 상반기 수의사·사육 전문가 검수 목표
- 사고 책임 → 설계 기준 공개, 검증 리포트 제공, 커뮤니티 공유 파일은 "NestForge 안전 검증을 거치지 않음" 표시 [확정, 운영 사이트 문구]

### 시장·사업
- 시장이 작다 → 15만 명은 시작점. 기준 조사가 끝난 6종으로 확장, 용품 브랜드 제작 파트너(B2B), 해외
- 무료 모델이 있는데 왜 돈을 내나 → 무료 모델은 남의 케이지 기준. 치수 맞춤, 종별 검증, 프린터 없는 사람의 수령까지 포함한 값
- 출력·배송 운영 → 초기 외주 출력(시간당 약 3,000원), 월 50건 이상이면 자체 프린터 전환, 프린터 1대(약 100만 원)는 100건 안에 회수 [가정]
- 고객 확보 채널 → 소동물 커뮤니티, 보호자 가이드 콘텐츠, 체험단 20가구 후기 [가정]
